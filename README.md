- [ ] `예외상황`: 당첨 번호에 중복된 숫자가 존재하는 경우

- [ ] `예외상황`: 당첨 번호에 `,`만 있는 경우

- [ ] `예외상황`: 보너스 번호가 숫자가 아닌 경우
- [ ] `예외상황`: 보너스 번호가 null인 경우
- [ ] `예외상황`: 보너스 번호가 빈 문자열인 경우
- [ ] `예외상황`: 보너스 번호가 음수인 경우
